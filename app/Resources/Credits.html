A native macOS client for browsing and transferring files on a Nintendo Switch running DBI's MTP responder.

Built on

  • SwiftMTP by Neighbor_Z — the macOS app this is derived from (GPL-2.0)
  • go-mtpfs by Han-Wen Nienhuys / Google, and the fork by Ganesh Rathinavel — the MTP engine (New BSD)
  • ganeshrvel/usb by Ganesh Rathinavel, from hanwen/usb — libusb bindings for Go (New BSD)
  • libusb by the libusb project — USB access, bundled as a shared library (LGPL-2.1-or-later)

Talks to

  • DBI by duckbill / rashevskyv — the Switch-side MTP responder. SwitchMTP is an unaffiliated client and bundles no part of DBI.

Learned from

Consulted while building this, but no code from them is included:

  • Awoo-Installer by Huntereb, whose USB install code originates with Adubbz (Tinfoil) — documentation of the TUL0/TUC0 USB install protocol
  • ns-usbloader by developersu — reference for the same protocol
  • libnx and GoldLeaf — identifying the shared homebrew USB product ID
  • switchbrew — Horizon OS and USB documentation
  • MTP (Media Transfer Protocol) and PTP (ISO 15740) specifications — the operation and property codes the backend is built on
